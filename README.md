# JWSteel 통합전산 — 배포

(주)정원철강 사내 회계/매출/매입 통합 ERP.

## 다운로드

최신 설치 마법사: [Releases](https://github.com/hanyeonsoo/jwsteel-release/releases/latest)

## 설치 방법

1. **JWSteel_Setup_v3.0.0.exe** 다운로드
2. 더블클릭 → 설치 마법사 따라가기
3. 바탕화면/시작메뉴 아이콘으로 실행

## 시스템 요구사항

- Windows 10 / 11 (64-bit)
- 디스크 700 MB 이상 여유 공간
- 인터넷 연결 (Supabase 클라우드 DB 연동)

## 변경 이력

각 버전의 변경 내역은 [Releases](https://github.com/hanyeonsoo/jwsteel-release/releases) 페이지를 참고하세요.
